# StreamPulse — StreamOverlay & AI Clip Studio

Спецификация веб-приложения для стримеров: два модуля — редактор вертикальных клипов с AI-разметкой и конструктор оверлеев для OBS.

## 1. Стек

- **Next.js 14+ (App Router)**, TypeScript
- **Tailwind CSS** — вся стилизация
- **Lucide React** — иконки
- **Framer Motion** — микроанимации, переходы
- **Canvas API / HTML5 Video** — превью вертикального кропа, отрисовка субтитров поверх видео
- **Zustand** — глобальный стейт редактора (текущий проект, выбранный клип, тайминги, настройки оверлея)

Внешние платные API (реальная транскрипция, реальный AI-анализ) не подключаются — везде используются встроенные демо-данные, чтобы приложение выглядело полностью рабочим сразу после `npm run dev`.

## 2. Дизайн-система

**Фон и поверхности:**
- Base background: `#090A0F`
- Surface (панели, карточки): `#12151F`
- Border: `#1E2333`

**Акценты:**
- Twitch-фиолетовый: `#9146FF`
- Кибер-бирюзовый: `#00F0FF`
- Неоновый лайм: `#22C55E`

**Стиль:**
- Glassmorphism-панели: `background: rgba(18,21,31,0.6)`, `backdrop-blur`, тонкая `border` в `#1E2333`
- Плавные микроанимации (hover, появление панелей, переключение табов) через Framer Motion, длительность 150–250ms
- Тёмная тема — единственная, без переключателя light/dark

Токены цвета задаются в `tailwind.config.ts` (`background`, `surface`, `border`, `accent-purple`, `accent-cyan`, `accent-lime`) и переиспользуются во всех компонентах.

## 3. Структура маршрутов

```
/                       — лендинг/выбор модуля
/clip-studio            — AI Clip Studio
/overlay-studio         — OBS Overlay Studio (конструктор, требует авторизации в контексте демо — без реального auth)
/overlay/[id]           — чистая страница оверлея для OBS Browser Source (прозрачный фон, без чужого UI)
```

## 4. Модуль 1 — AI Clip Studio

Вертикальный редактор для нарезки Shorts/Reels/TikTok из горизонтального контента (стрим/геймплей).

### 4.1 Источник видео
- Загрузка своего файла (`<input type="file" accept="video/*">`, локальный `URL.createObjectURL`, без бэкенда)
- Либо выбор одного из 3–4 встроенных демо-роликов (заглушки/сэмплы, лежащие в `public/demo/`)

### 4.2 Превью 9:16
- Canvas/video-контейнер с фиксированным соотношением 9:16
- Кадрирование: верхняя часть кадра — facecam (кружок/прямоугольник камеры), нижняя — геймплей/контент
- Границы кропа настраиваются перетаскиванием (drag) в пределах превью

### 4.3 AI Highlight Timeline
- Горизонтальная таймлайн-полоса под плеером с шкалой времени
- Цветные метки пиков активности поверх полосы: смех (лайм), крики (фиолетовый), экшен (бирюза) — генерируются из демо-датасета таймкодов (JSON), не реального анализа аудио
- Клик по метке — переход плеера к этому моменту
- Кнопка «Нарезать» рядом с каждым пиком — мгновенно создаёт клип с отступами ±N секунд от метки

### 4.4 Караоке-субтитры
- Генератор субтитров поверх видео, синхронизированных с демо-транскриптом (встроенный JSON с текстом и таймкодами слов)
- Анимация выделения текущего слова (подсветка/масштаб) в такт таймкодам
- Пресеты шрифтов/стилей на выбор: **MrBeast** (жирный, обводка, жёлтый), **Cyberpunk** (неон, бирюза/фиолетовый глоу), **Minimal** (тонкий, белый, без обводки)

## 5. Модуль 2 — OBS Overlay Studio

### 5.1 Конструктор оверлеев
- Виджеты: алерт донатов, чат-виджет, счётчик фолловеров
- Настройка каждого виджета: цвета (из палитры акцентов), позиция, размер, длительность анимации алерта
- Настройки сохраняются в Zustand-сторе и превью обновляется вживую

### 5.2 Live Test
- Кнопка «Отправить тестовое событие» (донат/подписка/фолловер) — эмулирует событие локально (через стор/`postMessage`), запускает анимацию алерта в превью и на странице `/overlay/[id]`

### 5.3 Страница оверлея (`/overlay/[id]`)
- Полностью прозрачный фон (`background: transparent`), без какого-либо чужого UI/навигации — только сами виджеты
- Читает конфигурацию оверлея по `id` (из localStorage/демо-стора, без реального бэкенда)
- Предназначена для вставки как Browser Source в OBS

## 6. UI/UX требования

- Адаптивность: рабочий десктоп-лейаут приоритетен (основной сценарий использования — стример за ПК), но страницы не должны ломаться на планшете
- Плеер отзывчив: play/pause/seek без задержек, использование нативного `<video>` под капотом Canvas-оверлея
- Все демо-данные (ролики, транскрипты, тайминги пиков, примеры донатов) встроены в проект — приложение выглядит полностью готовым сразу после запуска, без внешних ключей и сетевых запросов к платным API
